HORROR PLAYER QUIZ  (v1 Full-release)
======================================


How to play (EN)
1.Download zip file in releases Menu (NOT the source code zip)
2.Extract the whole zip first.
3.Double-click index.html. It opens in your browser 
or right click and choose "open with" and choose Microsoft Edge or google chrome.

*Keep all files together in this folder:
index.html, manifest.webmanifest, sw.js, icons/icon-512.png*

-Works offline, but you get your device's fonts and the player statistics shows a fun estimate.
-The Install button only works on the website, not from a local file.
-Full website: https://horror-player-quizbypoy.nrbdiyunyaw.workers.dev/


วิธีเล่นเกมนี้ (TH)
1.ดาวน์โหลดไฟล์ซิปในเมนู "releases" (ไม่ใช่ไฟล์ zip source code )
2.แตกไฟล์ zip ทั้งหมดก่อน (คลิกขวา > Extract All / แตกไฟล์)  
3.ดับเบิลคลิกไฟล์ index.html หรือคลิกขวาแล้วเลือก "เปิดด้วย" (Open with) จากนั้นเลือก Microsoft Edge หรือ Google Chrome"
  
*อย่าลบหรือย้ายไฟล์ออกจากโฟลเดอร์นี้*

- เล่นได้แม้ไม่มีเน็ต แต่ฟอนต์จะเป็นฟอนต์ของเครื่อง และสถิติผู้เล่นจะเป็นตัวเลขสนุกๆ
- ปุ่มติดตั้งแอปใช้ได้เฉพาะบนเว็บ ไม่ใช่ไฟล์ในเครื่อง
